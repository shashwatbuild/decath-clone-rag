## What the demo shows

| Journey | Demonstrated actions |
|---|---|
| Ask and verify | Multi-part question → cited answer → open source guide |
| Compare and continue | Compare catalogue fields → inspect product → return to saved chat |
| Choose and refine | Guided questions → recommendation → change priority → Undo |
| Buy thoughtfully | Owned-gear choices → kit totals → evidence, conditions, shared kits and reuse |
| Plan on mobile | Setup → ownership exclusion → weekly summary → expand a week |
| Prepare an adventure | Choose activity and budget → reuse gear → checklist progress → save |
| Try a sport | Sample date and duration → save personal plan → reflection controls |
| Remember fit | Save labelled demo feedback with consent → recall size on the same product |
| Preview clothing | Garment selection and camera adjustment controls; no person filmed |
| Checkout | Choose size → add to shared cart → inspect simulated checkout |

The fit record shown is synthetic demonstration data and was removed afterwards. Trial dates are sample personal plans, not bookings. Camera tracking on a person is not demonstrated. Checkout stops before placing an order. Optional dense retrieval requires separate setup; no competitor-exclusivity or general accuracy claim is made.

## YouTube publishing copy

**Suggested title:** I built a RAG sports shopping companion | Real app demo in 4K

**Description:**

A step-by-step walkthrough of my personal sports shopping project, built with Next.js, React and an evidence-backed RAG assistant. Follow the journey from a question and cited sources to product comparisons, an editable shopping brief, ownership-aware kits, weekly purchase planning, adventures, first-session planning, fit memories and simulated checkout.

The project connects catalogue retrieval with explicit rules for budgets, sizes, ownership and cart actions. The camera chapter demonstrates supported-top controls; it does not show live tracking on a person. Fit feedback is sample data. This is an independent portfolio prototype, not an official Decathlon product.

Source code: https://github.com/shashwatbuild/decath-clone-rag
