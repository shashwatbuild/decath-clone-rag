# How this project differs from Decathlon's chatbot

[Project](../README.md) · [Implemented features](FEATURES.md)

This personal project explores shopping decisions through an editable brief, cited evidence, ownership-aware kits and reversible changes. It is a prototype built around a bundled catalogue, not a replacement for Decathlon's retail or support systems.

Decathlon India's [official customer-support page](https://www.decathlon.in/support/695/decathlon-sports-india-customer-support-channels) directs customers to chat through its website or app. That establishes a support channel; it does not document the chatbot's complete AI capabilities. The page was checked on **28 November 2026**.

| Area | This project demonstrates | What the reviewed official page establishes |
|---|---|---|
| Main journey | Product discovery, comparison, planning and simulated shopping. | A website/app customer-support chat channel. |
| Choosing gear | Editable requirements, must-haves, preference trade-offs and Undo. | It does not describe equivalent chatbot workflows. |
| Evidence | Cited guide/policy answers and product eligibility checks. | It does not describe equivalent evidence controls. |
| Ownership and planning | Owned-item records, weekly purchases, kit scenarios and shared team equipment. | It does not describe equivalent chatbot planning controls. |
| Trying and remembering | Personal trial plans, exact-item fit memories and a bounded photographic camera preview. | It does not describe equivalent chatbot workflows. |
| Real operations | Bundled data and simulated checkout; no order fulfilment or venue booking. | Decathlon provides an official retail/support experience. |

**“Not described” does not mean “not available.”** This is a comparison of this project's implemented scope with the cited public page, not an audit of Decathlon's current chatbot. Claiming better accuracy, customer satisfaction or conversion would require comparable tasks and measured outcomes in both systems.

The intended customer benefits—clearer choices, fewer duplicate purchases and easier follow-through—are documented in the [feature matrix](FEATURES.md). They are design goals, not measured business results.
